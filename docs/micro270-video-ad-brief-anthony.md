## Video ad (preferred): 20–30 second screen recording

**Goal:** Show real product + trust + price in one short clip. **No voiceover** — text overlays only.

**Record:** Desktop — **QuickTime (Mac)** or **OBS (Windows)**. Full browser window, **1080p** if possible.

### Suggested flow

1. **0–3s** — Full-screen text on black or subtle blurred background:  
   `I couldn't find a good micro study tool...`

2. **3–8s** — Same style:  
   `...so I built one`

3. **8–20s** — **Screen recording**
   - Open **https://nopriorauthorization.com/micro270/hub**  
     *(Alternative: start on https://nopriorauthorization.com/micro270 → click **Start free** → lands on hub.)*
   - Click **Chapter 13 — Antimicrobial Drugs** (use **Launch** if that’s how it opens).
   - Pick a **trap** question, **reveal** the answer, then **scroll** so the **explanation** is clearly visible (this is the “wow” beat).

4. **20–25s** — Navigate to **https://nopriorauthorization.com/micro270#pricing** and frame so **$47 / $67 / $97** is readable.

5. **25–30s** (if using 30s) — Hold on pricing or end card: logo + **nopriorauthorization.com/micro270**

## Budget recommendation (Meta-style, conservative)

**Learning / test (first ~7 days)**  
- **$15–25/day** total, **1–2 ad sets** max (e.g. nursing student interests; add lookalikes only after pixel data exists).  
- If the pixel is cold: start with **Traffic** or **Engagement**; move toward **Sales** once checkout/purchase events are reliable.

**After a winning creative + audience**  
- **$30–50/day** on the winner; duplicate new tests **slowly** (avoid 10 clones of the same ad).

**Rough monthly “real” test band**  
- **~$500–800/mo** for US-only learning + modest scale **if** unit economics support it.

**Creative split**  
- **~70%** budget on the **video**; **~30%** on the **static** backup after the video has 3+ days of data.

**KPIs**  
- 3-second video plays / thumb-stop, **CTR** (link), **CPC** outbound click, then **initiate checkout** / purchase if tracked.
