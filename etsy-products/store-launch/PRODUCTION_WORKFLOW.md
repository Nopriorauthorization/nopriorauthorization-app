# Production Workflow

This is the repeatable system for building Etsy products without custom-designing every listing from scratch.

## The 3 Layers

Keep the shop organized in three layers:

1. `store-launch/` = strategy, copy, storefront assets, listing docs
2. `canva-automation/output/products/` = customer delivery files and ZIPs
3. Canva = editable design source

If those three layers stay clean, the store stays manageable.

## Master Families

You only need a small number of reusable creative families.

### Product families

- Core service bundles
- Entry mini packs
- Multi-service bundles

### Visual families

- hero thumbnail
- what is included slide
- category breakdown slide
- preview grid slide
- credibility slide
- how it works slide
- FAQ or customization slide

### Brand image rule

- use high-end photos
- keep imagery luxury and editorial
- avoid cartoon characters and mascot-style artwork
- avoid illustration-led slides unless they are purely small support icons

### Content families

- education
- myths vs facts
- promotions
- consultation prep
- trust and credibility
- seasonal campaigns
- membership and retention

## Repeatable Build Sequence

### 1. Choose the SKU

Pick:

- service line
- pack type
- buyer
- price tier

Examples:

- IV core bundle
- GLP-1 mini pack
- Botox promo pack
- Complete Injector bundle

### 2. Reuse an Existing Family

Do not start from blank.

Duplicate:

- the last listing doc
- the last 7-image structure
- the closest Canva layout family
- the closest product output folder structure

### 3. Build the Offer

Define:

- title
- promise
- counts
- what is included
- cross-sell path
- compliance notes

### 4. Build the Assets

For every listing, create:

1. hero thumbnail
2. what is included
3. breakdown slide
4. preview grid
5. credibility slide
6. how it works
7. FAQ or customization

### 5. Build the Product Output

Make sure the product folder includes:

- PNG or PDF deliverables
- Canva links if applicable
- instructions
- compliance guide if promised
- ZIP output

### 6. Publish Check

Before Etsy upload:

- ZIP matches the listing promise
- listing images match the current visual system
- links open correctly
- previews are not blank
- cross-sells are added

## Weekly Cadence

### Good founder-friendly pace

- 1 core listing every 1-2 weeks
- 1 entry pack each week in between
- 1 bundle after every 2 related cores

### Suggested pattern

Week 1:

- build one core listing

Week 2:

- build second core listing
- add cross-sell references

Week 3:

- publish bundle using those two cores

Week 4:

- build one mini pack that points back to the two cores

Repeat.

## When To Make a New SKU

Make a new SKU when:

- the product serves a different buyer job
- the deliverables are different enough to justify a new listing
- the price tier changes
- the keyword intent changes

Reuse an existing SKU when:

- the offer is still the same
- you are only improving screenshots
- you are fixing copy or compliance language
- the update would not confuse past buyers

## Best Batching Strategy

Batch by task, not by product.

### Batch A

Write 3-5 listing concepts at once.

### Batch B

Create all hero thumbnails at once using the same high-end photo direction.

### Batch C

Create all `what's included` and `how it works` slides at once.

### Batch D

Run ZIP and Canva-link QA in one sitting.

### Batch E

Upload multiple Etsy listings in one admin session.

## Golden Rule

You are not building hundreds of unique products.

You are building:

- a catalog system
- a trust system
- a production system

Once those are stable, the store grows by duplication and adaptation, not reinvention.

## Non-Negotiable Visual Guardrail

`No Prior Authorization` should always look like a high-end med spa brand.

That means:

- elegant photography first
- minimal design support elements second
- no cartoon people
- no fake mascot-style graphics
- no low-end template-market visuals
