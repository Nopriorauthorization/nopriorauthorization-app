# No Prior Authorization Etsy Store Launch

This folder is the working package for the `No Prior Authorization` Etsy shop build.

It turns the approved store plan into copy-ready storefront assets, listing systems, and launch docs that can be reused as the catalog expands.

## Contents

- `positioning.md` - store promise, buyer profile, differentiators, voice
- `launch-catalog.md` - first 8 listings, pricing ladder, launch order
- `SCALABLE_CATALOG.md` - how one service line expands into many Etsy SKUs
- `visual-system.md` - thumbnail rules, listing-image rules, brand system
- `PRODUCTION_WORKFLOW.md` - repeatable workflow for building products at scale
- `NEXT_10_LISTINGS.md` - exact next wave of listings to build after the first 3
- `storefront-copy.md` - banner copy, announcement, About, FAQ, trust messaging
- `listings/` - Etsy-ready docs for the first 3 launch listings
- `backlog/next-five-products.md` - production briefs for the next 5 listings
- `assets/README.md` - generated storefront and listing image asset map
- `ETSY_API_APP.md` - register an Etsy Open API app (OAuth, env vars, redirect URIs)

## Launch Priorities

1. Publish the 3 anchor listings:
   - `IV Therapy Social Media Bundle`
   - `Medical Weight Loss Social Media Bundle`
   - `Complete Med Spa Bundle`
2. Use one visual system across every listing before adding more products.
3. Cross-sell the bundle from both single-service listings.
4. Expand next into Botox, filler, promo, myths/facts, and membership-style offers.
