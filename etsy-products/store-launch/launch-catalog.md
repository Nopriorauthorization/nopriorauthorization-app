## Merchandising Rules

- Every core listing should point up to a bundle
- Every entry listing should point up to a core service bundle
- The bundle should mention savings versus buying singles
- Related products should be named and shown inside listing images where possible

## Price Logic

- IV is the accessible core offer
- Weight loss carries a premium because the category is higher value and more clinically specific
- The combo bundle should feel like the obvious upgrade for dual-service med spas
- Entry products create first-purchase velocity without competing directly with the hero bundles
