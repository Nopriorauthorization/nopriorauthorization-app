# Visual System

## Brand Palette

| Token | Hex | Use |
|------|-----|-----|
| Hot Pink | `#D4537E` | Primary accent, CTA bars, badges, highlights |
| Black | `#1A1A1A` | Dark backgrounds, strong text |
| White | `#FFFFFF` | Text on dark, clean preview backgrounds |
| Blush | `#FBEAF0` | Soft checklist and support slides |
| Charcoal | `#333333` | Secondary body text |
| Light Gray | `#F5F5F5` | Secondary backgrounds |

## Typography

| Role | Font | Use |
|------|------|-----|
| Display | `Playfair Display` | Listing headlines and elegant hero text |
| Display Alt | `Cormorant Garamond` | Optional editorial accents |
| Body | `Lato` | Listing support text and subheads |
| Body Alt | `Montserrat` | Secondary template copy |
| Accent | `Pinyon Script` | Rare quote or celebration accent only |

## Photography Direction

This brand is photo-led.

- Use high-end beauty and clinical photography
- Use premium real-photo or photoreal editorial imagery
- Keep photo choices polished, minimal, and luxury-forward
- Match the look of a high-end med spa, not a budget template shop

Do not use:

- cartoon characters
- mascot-style figures
- flat illustrations as hero imagery
- childish icons or playful clip art
- obvious fake character graphics

## Thumbnail Formula

Every primary Etsy thumbnail should use the same structure:

1. Top line: service or niche in white display type
2. Second line: product type in pink body type
3. Center: 3-4 template previews or mockups
4. Bottom-left: 2-3 pink value badges
5. Bottom-right: `No Prior Authorization` plus `by Hello Gorgeous Med Spa`
6. Corner: small pink `INSTANT DOWNLOAD` pill

## Listing Image System

Use the same seven-image system across the shop.

1. Main hero thumbnail
2. What is included
3. Category or deliverable breakdown
4. Template preview grid
5. Created by real providers
6. How it works
7. FAQ or customization steps

## Badge Rules

- Keep badges short and count-based when possible
- Limit hero badges to 2-3 max
- Use hot pink as the primary badge color
- Avoid long sentences inside badges
- Use trust badges only on credibility slides, not every image

## Sizing Rules

- Etsy listing images: `1600 x 1200`
- Square post templates: `1080 x 1080`
- Portrait templates: `1080 x 1350`
- Story templates: `1080 x 1920`

## Design Do

- Use high contrast
- Keep layouts readable in under 3 seconds
- Use real template previews whenever possible
- Use premium photo-led visuals wherever imagery appears
- Keep CTA bars clean and slim
- Preserve negative space
- Use 1-2 visual anchors only

## Design Do Not

- Do not overcrowd the hero image
- Do not use heavy glow or neon bloom
- Do not mix too many fonts
- Do not use cluttered stock-photo-heavy layouts
- Do not use cartoon or illustrated character graphics
- Do not make medical claims in thumbnails
- Do not rely on Pro-only Canva elements
