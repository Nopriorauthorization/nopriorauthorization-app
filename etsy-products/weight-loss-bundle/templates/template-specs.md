# Brand Guidelines

## Color Palette
| Color | Hex Code | Usage |
|-------|----------|-------|
| Hot Pink | #D4537E | Primary accent, CTAs, highlights |
| Black | #1A1A1A | Headlines, strong text |
| White | #FFFFFF | Backgrounds, body text on dark |
| Blush | #FBEAF0 | Soft backgrounds, feminine accent |
| Charcoal | #333333 | Body text alternative |
| Light Gray | #F5F5F5 | Secondary backgrounds |

## Typography
| Use | Font | Weight | Notes |
|-----|------|--------|-------|
| Headlines | Playfair Display | Bold | Elegant, medical-luxe feel |
| Subheads | Cormorant Garamond | SemiBold | Alternative headline option |
| Body | Lato | Regular | Clean, readable |
| Body Alt | Montserrat | Regular | Modern alternative |
| Accent | Pinyon Script | Regular | Sparingly, for quotes |

## Dimensions
- **Square Post:** 1080 x 1080px
- **Portrait Post:** 1080 x 1350px
- **Story:** 1080 x 1920px
- **Carousel:** 1080 x 1080px (multi-slide)

# Production Notes

## File Delivery
- All templates delivered as Canva "Use this template" links
- Organized in PDF document by category
- Each link opens template in user's Canva account

## Quality Assurance
- [ ] All fonts are free Canva fonts
- [ ] No Pro-required elements
- [ ] Colors match brand palette
- [ ] Text is editable
- [ ] Placeholders clearly marked
- [ ] Mobile preview checked
- [ ] Download tested (PNG/JPG)

## Naming Convention
```
NPA_WL_[Category]_[Number]_[ShortName]
```
