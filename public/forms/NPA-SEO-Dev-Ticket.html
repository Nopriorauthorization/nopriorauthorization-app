1. Meta tags — every page needs a unique title and description
Code 2 hrs

Every page needs a unique <title> tag and <meta name="description">. These are what appear in Google search results. Generic or missing tags = invisible to Google. Use this exact pattern:

// Homepage title: "No Prior Authorization | Med Spa Business Systems by Danielle Alcala" description: "Playbooks, templates, and tools built inside a real med spa — so you don't spend years figuring out what nobody taught you. Free digital audit included." // /playbooks title: "Med Spa Playbooks | Clinical & Business Systems — NPA" description: "Complete playbooks for Botox, GLP-1, IV therapy, hormone therapy, peptides, and more. Built by a med spa founder. Instant download." // /audit title: "Free Med Spa Digital Audit | Score Your Online Presence — NPA" description: "Find out exactly what's costing you patients on Google. Free scored report in 60 seconds. No credit card required." // /shop title: "Med Spa Templates & Consent Forms | NPA Shop" description: "Clinical consent forms, patient communication kits, aftercare cards, and social media templates. Instant download. Built for aesthetic providers." // /membership title: "NPA Pro Membership | Every Med Spa Product for $47/month" description: "Access all 22+ playbooks, kits, and templates. New products added monthly. Cancel anytime. Built by a med spa founder who actually runs one."

Character limits: Title = 50–60 characters max. Description = 150–160 characters max. Every page. No exceptions.

2. Schema markup — tell Google exactly what NPA is and who Danielle is
Code 3 hrs

Schema is structured data that Google reads to understand your business. Without it Google guesses. With it Google knows. Add both blocks to the homepage <head>:

// LocalBusiness + Person Schema — paste in <head> as JSON-LD <script type="application/ld+json"> { "@context": "https://schema.org", "@graph": [ { "@type": "Organization", "name": "No Prior Authorization", "url": "https://nopriorauthorization.com", "logo": "https://nopriorauthorization.com/logo.png", "description": "Med spa business systems, playbooks, and tools built by Danielle Alcala, founder of Hello Gorgeous Med Spa.", "founder": { "@type": "Person", "name": "Danielle Alcala", "jobTitle": "Founder, Licensed Esthetician", "worksFor": "Hello Gorgeous Med Spa" }, "sameAs": [ "https://instagram.com/nopriorauthorization", "https://linkedin.com/in/daniellealcala", "https://etsy.com/shop/nopriorauthorization" ] }, { "@type": "Person", "name": "Danielle Alcala", "jobTitle": "Med Spa Founder & Business Educator", "url": "https://nopriorauthorization.com/about", "image": "https://nopriorauthorization.com/danielle-alcala.jpg", "description": "Danielle Alcala is the founder of Hello Gorgeous Med Spa in Oswego, Illinois and creator of No Prior Authorization — the business platform for aesthetic providers.", "sameAs": [ "https://instagram.com/daniellealcala", "https://linkedin.com/in/daniellealcala" ] } ] } </script>

Also add Product schema to every product page — this enables Google to show star ratings and prices directly in search results (rich results). Use the Product type with name, description, offers, and aggregateRating.

3. Sitemap.xml + robots.txt — make every page crawlable
Code 1 hr

The sitemap tells Google every page that exists. Robots.txt tells Google what it can and can't crawl. Both are required before submitting to Google Search Console.

// Next.js — add to next.config.js or use next-sitemap package npm install next-sitemap // next-sitemap.config.js module.exports = { siteUrl: 'https://nopriorauthorization.com', generateRobotsTxt: true, sitemapSize: 7000, exclude: ['/admin/*', '/api/*', '/delivery/*'], robotsTxtOptions: { additionalSitemaps: [ 'https://nopriorauthorization.com/sitemap.xml', ], }, } // package.json — add to postbuild "postbuild": "next-sitemap"

After deploying — submit the sitemap URL to Google Search Console: https://nopriorauthorization.com/sitemap.xml

4. Google Search Console + Google Analytics 4 — the monitoring layer
Analytics 2 hrs

Without these two tools you're flying blind. Search Console shows what searches bring people to the site, which pages are indexed, and any errors Google finds. GA4 shows traffic, conversions, and user behavior.

Code 3 hrs

8. FAQ page with structured data — 40 questions, Google rich results
SEO 2 hrs

The FAQ page is already built in the Google Domination Playbook. Anthony needs to build a static FAQ page at /faq with all 40 questions and add FAQPage schema so Google can show the answers directly in search results.

// FAQPage Schema — add to /faq page { "@context": "https://schema.org", "@type": "FAQPage", "mainEntity": [ { "@type": "Question", "name": "How long does Botox last?", "acceptedAnswer": { "@type": "Answer", "text": "For most patients, Botox lasts 3 to 4 months..." } }, { "@type": "Question", "name": "What is the difference between Botox and filler?", "acceptedAnswer": { "@type": "Answer", "text": "Botox relaxes muscles to reduce dynamic wrinkles..." } } // ... repeat for all 40 questions ] }

FAQ schema can trigger Google rich results — your FAQ answers appearing directly under the NPA search result. This significantly increases click-through rate without any paid advertising.
